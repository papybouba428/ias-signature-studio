Comment l'installer sur Outlook ?

Ouvrez Paramètres → Comptes → Signatures dans le nouvel Outlook ou Outlook Web, créez une signature et collez le contenu copié. Pour Outlook classique : Fichier → Options → Courrier → Signatures. Envoyez un email test.

ACCÈS RESTREINT

Pilotez les campagnes IAS.

Seul l'administrateur peut publier, modifier, ordonner et désactiver les visuels.

Connexion administrateur

Connectez-vous avec votre compte Microsoft IAS. Seuls les comptes ayant le rôle administrateur accèdent aux campagnes.

Site web et réseaux sociaux IAS

Ces liens sont communs à toutes les signatures et s’appliquent aussi aux signatures déjà installées. Les liens officiels de l’IAS sont proposés par défaut ; laissez vide un réseau non utilisé.
