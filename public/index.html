Comment l'installer sur Outlook ?

Ouvrez Paramètres → Comptes → Signatures dans le nouvel Outlook ou Outlook Web, créez une signature et collez le contenu copié. Pour Outlook classique : Fichier → Options → Courrier → Signatures. Envoyez un email test.
